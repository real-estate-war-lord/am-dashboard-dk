# P4 — Map: Climate as an indicator, Layers ▾ menu, unified search, legend stack

## Scope (spec §1 decision 3, §4.4, §4.5, §5.1, ENG_BRIEF §1.9)
1. **Climate is an indicator family, not an overlay.** Delete the `Climate risk` button, `MK.clim` toggle and
   its floating filter card. When the active indicator is a Climate indicator, the storm-surge zones + official
   risk areas for the active horizon draw automatically as a context layer (zoom ≥ 10 for zones), with their
   own legend card (`legend-zones`) and a `[data-layer=zones]` row in the Layers menu to hide them (`zones=0`).
   Non-climate indicator → no zones, no zones legend. Old `climate=1` links → climate indicator (route_core).
   The Climate chip stays in the chips row.
2. **Layers ▾** (`layers-btn`, `layers-pop`): Infra projects, Public buildings (+ category/kind filters moved
   out of the legend card), Services (+ category filters), Context: zones (only when climate), test-property
   radius (only when a pin exists). Count badge `Layers · n`. URL key `lay=` (keep accepting the old
   `infra=1&public=1&services=1` keys). Legend cards become keys-only, stacked bottom-right, never overlapping,
   ≤ 60 % of map height (AC-LG1).
3. **Toolbar = one row** at ≥ 1366 px: `[search][Layers ▾][Indicator ▾][Period]` (+ drilled-state segments for
   Copenhagen quarters/postal codes and Areas/Buildings), chips row below, info strip below that. Full-screen
   button moves to the top bar right. Map top ≤ 200 px at 1366×768 (AC-S3).
4. **Unified search**: one combobox for municipality / postal code / quarter names+codes AND Google Maps links /
   `lat, lon` (reuse `parseLocation`). Coordinates show a `search-coord` result "Open as test property" →
   `#property?p=…`. "Jump to: Denmark · Copenhagen" at the top of the dropdown replaces the jump buttons (keep
   the C/D keyboard shortcuts). Remove the second "Paste Google Maps link" box from the map; the privacy sentence
   becomes a `?` tooltip.
5. Outlook indicators use the purple ramp on the map; climate the blue ramp (AC-M4).

AC-L1, AC-L2, AC-L3, AC-LG1, AC-M1, AC-M2, AC-M3 (read `#properties` as `#property`), AC-M4, AC-S3.
