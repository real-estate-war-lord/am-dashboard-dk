# P5 — Area page rebuild (the study row)

## Scope (spec §5.2, §4.6, §4.7, §2.4; owner wish 5)
1. Layout: header (title, pills, actions `Show on map`, `↗ Chart`, `Buildings ›`) → **headline tiles** (clickable
   = select indicator; inherited tiles `.inh` + "municipality figure"; projection pill) → **IndicatorPicker +
   PeriodControl + chips** (the P3 components; postal/quarter pages list inherited indicators under
   "From the municipality" with `.tag-muni`) → **study row** (`data-testid=study-row`): **chart panel 60 %
   left | mini-map 40 % right, equal height** → toggles as `<details>`: Population outlook (open by default on
   municipality pages) · All figures · Postal codes / Quarters · Data information; open state in `show=`.
2. Build the study row as a **reusable component** (`studyRow(entity, opts)`) — P6 uses it for the test property.
3. Chart panel modes: History line (area solid, parent, peer median dashed, Denmark dashed for municipalities),
   Snapshot → `state-nohistory` + distribution strip (`dist-strip`), Outlook → the outlook chart
   (`outlook-chart`), Climate → three horizon bars (`clim-bars`) with a `Climate sheet ›` link. Headline row in
   the panel: value, Δ y/y, rank `#n of N` (N = peers with a value), vs median; footer with source · table ·
   as of · Verify ↗.
4. Mini-map (§4.6): draggable, scroll zoom, `⤢` full screen overlay (Esc closes, `invalidateSize`), legend
   inside, selected area outlined, click a neighbour → its page, **zoom never selects**. Selecting an indicator
   updates panel + map **in place** (no full re-render; scroll position kept — AC-P4; must work while the map is
   full screen).
5. Remove the KEY FIGURES block (12 tabs × cards), the separate Trend and Neighbours cards, duplicate buttons.
6. Quarter pages: keep the KK vs DST outlook note and Safety survey inside All figures. Where KK `new_stock` and
   BBR `new_stock_bbr` differ by > 15 pp, rename the labels per ENG_BRIEF §3.4 ("Dwellings commissioned 2010+
   (KK, dwelling)" / "Dwellings in buildings built 2010+ (BBR, building year)") and show a one-line caveat.
   Label change in the UI only — no data change.
