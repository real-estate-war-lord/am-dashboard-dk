# P1 — Foundation: map lifecycle, test harness, route aliases (dormant), design tokens

Everything later depends on this phase. Keep behaviour and URLs identical to v2.6 except the bug fixes below.

## Scope
1. **Test harness into the repo.**
   - Move `docs/v3/ui_smoke_v3.py` → `tests/ui_smoke.py` (git mv). Keep its CLI (`--url --out --phase --only
     --viewports --allow-errors --no-network --full-page`).
   - Create `tests/ui_ac.py`: Playwright acceptance runner. Structure: a registry `AC = {}` of
     `@ac("AC-XX", phase="P1")` decorated functions `(page, base_url) -> None` raising AssertionError; CLI
     `--url --phase-upto P1 --only AC-.. --out`; runs every AC whose phase ≤ `--phase-upto`; boots the page once
     per viewport as ui_smoke does; blocks non-local network; writes `report.json`; exit 1 on any failure.
   - Makefile targets: `smoke:` and `ac:` (both expect a server on :8080), documented in `tests/README.md`.
2. **Map lifecycle (ENG_BRIEF §2.4 — fixes appendChild / intersects / _leaflet_pos).**
   - One `dropMap(key)` helper (`map.off(); map.stop(); map.remove()`; null the LF key and its renderers /
     layer groups) called for every live map at the top of `render()` before `#main` is replaced.
   - Per-map panes/renderers: helper `mapPanes(map)` creating `pubpane/srvpane/climpane` + canvas renderers,
     stored on `map._am`; `pubMarkers` and the services/climate builders read `map._am.*` of the map they draw on.
   - `L.Map.prototype` guards: `_onZoomTransitionEnd`, `_move`, `_getMapPanePos` return early when the map
     pane is gone (like the existing Canvas guard).
   - Debounce map inits: one `LF.initTimer`; each `xInit` re-checks `S.view` before building.
   - Test hook: `window.__maps` = array of live Leaflet maps (updated on create/drop).
3. **Analysis (test property) mini-map drags**: `dragging:true`, keep reader zoom/center across re-renders,
   add a `⌖` re-centre control. (Full screen comes in P6.)
4. **Route alias table, dormant**: `src/route_core.js` (IIFE → `window.ROUTE_CORE`) with the v3 alias table
   (old→new and new→internal view): `table/<lvl>`→`data/areas/<lvl>`, `pipeline`→`data/projects`,
   `market`→`data/national`, `sources`→`data/sources`, `analysis?a=&la=`→`property?p=lat,lon:label`,
   `compare?a=type:code…`→`area/<type>/<code>`, `map…&climate=1`→ same map with a climate indicator
   (`surge_dw_pct` unless `ind` already is climate). Pure functions + `tests/route.test.js`. Wire into
   parseHash behind `const ROUTE_V3 = false` so this phase emits the old hashes unchanged.
5. **Design tokens only**: add spec §2.1–2.3 tokens to `:root` in style.css (colours, spacing, type scale,
   focus ring). Don't restyle views yet.
