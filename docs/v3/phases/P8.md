# P8 — Responsive shell, number rules, sheets, accessibility

## Scope (spec §4.1, §6, §7, §2.4, §5.7, §4.10)
1. **App shell**: sidebar 240 px ≥ 1025 px; ≤ 1024 px → 52 px top bar (`topbar-mobile`) with `☰`
   (`nav-toggle`) opening a drawer (`nav-drawer`, scrim, Esc closes, focus trapped and returned). Page scrolls
   natively on mobile. Set `OVERFLOW_FATAL = True` in tests/ui_smoke.py: **no horizontal overflow on any route
   at 390, 1366, 1440, 1536**.
2. Responsive matrix §6 for every view (toolbars stack, study row stacks at ≤ 1024, tables scroll inside their
   card with sticky first column, tiles 5 → 3+2 → 2, legends collapse to a "Legend ▾" pill on mobile).
3. **Number rules sweep** (§2.4) through one `fmt` path: rank `#n of N` everywhere (N = peers with a value,
   `title` explains), small-base projections persons-first with `small base` tag, `–` vs `n/c`, projection
   `.proj` purple + pill, inherited `.inh` + label, signed changes with `pp` vs `%`.
4. **Sheets** (§5.7): no empty grey tile fillers (AC-SH1), climate sheet uses the shared PeriodControl and its
   "Show the zones on the map" → `#map/<kommune>?ind=surge_dw_pct&hz=…` (AC-SH2).
5. **Empty/loading/error states** (§4.10) with the `state-*` test ids where views load lazily.
6. **Accessibility**: `:focus-visible` ring, `aria-expanded` on all popover triggers, darken 11 px muted text
   to `#6F7168`. For AC-A1: axe-core cannot be downloaded during the night (no network installs). If
   `src/vendor/axe.min.js` already exists, inject it from disk in tests/ui_ac.py; otherwise implement AC-A1 as a DOM check (every button/input/select has an accessible
   name, popover triggers have `aria-expanded`, images/icons have text alternatives) and note it in PROGRESS.md.
   AC-A2 keyboard path.
